## 数据结构分析

### coordinateinfov3_2.bin 记录格式
- 记录大小: 10字节
- 起始偏移: 0x104 (260 decimal)
- 格式: `flag(1) + b1(1) + b2(1) + b3(1) + extra1(2) + extra2(2) + extra3(2)`
- Map ID解码: `(b3 << 8) + b1`
- 有效标志字节: `b2 == 0x8a` 或 `b2 == 0x8c`

### coordinatev3_2.bin 记录格式
- 记录大小: 8字节
- 格式: `index(4) + x(2) + y(2)` (x,y为有符号16位整数)
- 总记录数: 998,882

## 更新分析 (2026-04-07)

### Map 1000 (法兰城) 分析结果

**关键发现:**
- Map 1000 在 coordinateinfov3_2.bin 中**没有作为源地图的条目**
- 原因: info file 只编码 0x01xx 范围的地图 (256-511)，而 Map 1000 = 0x03E8，超出范围
- Map 1000 在 coordinatev3_2.bin 中有 **24个目的坐标条目**

**24个坐标条目 (val 分布):**
| val值 | 数量 | 坐标范围 |
|-------|------|----------|
| 0 | 6 | x=65, y=-69 (完全相同) |
| 1 | 3 | (-4,-66), (-9,-90), (-18,-83) |
| 2 | 8 | (0,-57), (1,-67), (2,-61), (2,-60) 等 |
| 3 | 3 | (-3,-73), (7,-53), (-2,-73) |
| 4 | 2 | (0,-30), (0,-33) |
| 5 | 2 | (-1,-60) |

**解释:** val 可能表示传送水晶类型，0=主水晶(多次触发点)，1-5=其他水晶

### Warp System 总结

**Info file (coordinateinfov3_2.bin):**
- 75个有效条目，64个唯一源地图 (280-511范围)
- 14个唯一目标地图 (zone boundaries: 4096-59392，都是256的倍数)
- 格式: `flag(1) + b1(1) + b2(1) + b3(1) + src_x(2) + src_y(2) + dest_map(2)`
- Map ID = (b3 << 8) + b1

**Coord file (coordinatev3_2.bin):**
- 998,882个条目
- 按目标地图分组，包含在该地图的落地坐标

**注意:** 法兰城(1000)的传送水晶系统似乎是独立的，不在分析的这个warp系统内
